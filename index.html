🔄 Sincronizar móvil y ordenador

Tus horas se guardan en el archivo horas.json de un repositorio de GitHub. Así todos tus dispositivos ven lo mismo.
Cómo conseguir el token
  1. Te recomiendo un repositorio privado solo para los datos (por ejemplo horas-datos), para que tus horas no sean públicas.
  2. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Repository access elige Only select repositories y marca ese repositorio.
  4. En Permissions → Contents: Read and write. Genera el token y pégalo aquí. Hay que pegarlo una vez en cada dispositivo.

💾 Copia de seguridad

Cargar una copia la mezcla con lo que ya tienes; no borra nada.
Usarla como programa de escritorio: abre esta página en Chrome o Edge y pulsa el icono de instalar (⊕) en la barra de direcciones, o ⋮ → Instalar Mis Horas. Se abrirá en su propia ventana, con icono en la barra de tareas.
